# Persönliche Website

Persönliche Website mit Lebenslauf, Projekten und einem passwortgeschützten Kalender. Gebaut mit Next.js und TypeScript, gehostet auf Vercel.

## Lokal starten

Voraussetzung: Node.js 20.9 oder neuer.

```bash
npm install
cp .env.example .env.local   # Werte eintragen
npm run dev
```

Die Seite läuft danach unter http://localhost:3000.
